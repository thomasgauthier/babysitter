## Prompt

`The palette IS correct. I will not approve any more counting or grep commands. You are in an exactness loop. Move to the verification sequence NOW: tic80ctl load flowers.lua and tic80ctl run. This is a directive.`

## Use When

- The model is spinning on character counts or formatting exactness.
- It has already tried to count the same thing more than once.

## Effect

- Breaks the counting loop and pushes the run back toward verification.
